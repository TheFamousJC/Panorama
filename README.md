# Panorama from 3Sci Labs

> **Daily Thoughts & Ideas Synthesizer**
> A zero-friction local thought scratchpad with an embedded holistic analyst for work and life.

## Features
- **Zero-Friction Capture:** Keyboard shortcut logging (Ctrl+Enter), quick category tagging, and in-browser voice dictation (Alt+V).
- **Ambient Desk Telemetry:** Live cognitive load distribution bar and sticky daily North Star priority.
- **Holistic AI Synthesis:** Asynchronous pattern analysis powered by Google Gemini (gemini-3.8-flash) or zero-cost manual prompt export for Claude / ChatGPT.
- **Multi-Week Chronic Snag Detection:** Distinguishes one-off frustrations from repeating systemic process debt.
- **Calendar & Action Exports:** One-click universal .ics focus blocks and markdown task checklists.
- **Data Sovereignty:** Private local storage, optional numeric PIN access lock, and complete JSON Vault backup & restore.

## Quick Start
Open \index.html\ directly in any modern browser (Chrome, Edge). No build step or node runtime required.
